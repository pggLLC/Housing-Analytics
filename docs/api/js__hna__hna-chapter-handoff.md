# `js/hna/hna-chapter-handoff.js`

hna-chapter-handoff.js — fill in "What you have now" at the end of each part.

The markup is generated by scripts/hna/build_hna_views.py with every figure
hidden. This copies the values out of the stat cells already on the page and
reveals only the ones that actually arrived.

WHY IT COPIES RATHER THAN COMPUTES

A summary that re-derives its own numbers is a second producer, and this
repo has spent a week on what that costs — co-county-demographics.json had
two producers disagreeing daily, both green. If the handoff said something
the panel above it did not, the reader would have no way to tell which was
right. So it quotes.

ABSENCE

A stat that never loaded reads as "—" in its card. Repeating that here would
be the same defect one more time: a dash looks like an answer. A figure that
is missing, dashed, or still a placeholder is dropped, and if none survive
the block says so plainly instead of showing an empty list under a heading
promising a summary.

_No documented symbols — module has a file-header comment only._
